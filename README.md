# Pokemon-Site---Wild-Encounter-
A simple site, which, through different API's creates an interactive experience, where the user can encounter different pokemons.
Created as an examproject, for a course focussing on datadriven applications

For this project, the following APIs have been use
- PokeAPI for sprites and stats: https://pokeapi.co/
- WeatherAPI for getting geolocation and weather type: https://www.weatherapi.com/
- OpenLibrarys for the books: https://openlibrary.org/developers/api
- Youtube API for youtube player: https://www.youtube.com/iframe_api

Background image and Pokeball has been taken from pixabay, all credits goes to the original artist:
- Background image: https://pixabay.com/illustrations/pokedex-pokemon-pokeball-video-game-5593125/
- Pokeball: https://pixabay.com/illustrations/pokeball-pokemon-game-ball-1594373/

Further the following dataset from Kagle has been used for the gender ratio table(is here named data.csv):
https://www.kaggle.com/datasets/rounakbanik/pokemon?resource=download

For proper use of the weather API, an API key must be obtained from the site, and put in on line 433
